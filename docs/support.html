Support

Questions, problems or ideas? Email info@vllasa.com or open an issue on GitHub. We usually reply within two business days.

Where is Puls after launching it?

Puls is a menu bar app and does not appear in the Dock. Its item with your live values sits in the top right of the menu bar. Click it to open the panel; right-click for a small menu.

How do I quit Puls?

Right-click the Puls item and choose Quit Puls, or open the settings with the gear button in the panel and click Quit.

How do I start Puls automatically?

The GitHub version does so from the first launch; the App Store version asks first. You can change it any time in the settings under Open at login.

Which values can I show in the menu bar?

CPU, graphics, memory, network, disk, temperature (GitHub version) and battery. Each can be switched on or off, with colored status indicators or in plain monochrome.

Why doesn’t the App Store version show CPU temperatures and fans?

Apps from the Mac App Store run in a protected environment, the App Sandbox, which does not allow access to the Mac’s temperature sensors and fans. The App Store version shows your Mac’s thermal state, the power draw and the battery temperature instead. The free version on GitHub runs without the sandbox and additionally shows CPU temperatures, fan speeds and the busiest processes.

Can I have both versions installed?

Please use only one. Both are called Puls; if you switch, quit the old one and delete it from the Applications folder first.

How do I update Puls?

The App Store version updates automatically. The GitHub version shows a notice in the panel when a new release is available; download it and replace the app in your Applications folder.

Which languages are supported?

English and German. Puls follows the language set in System Settings, General, Language and Region.

System requirements

macOS 26 Tahoe or later, on Macs with Apple silicon or Intel.
